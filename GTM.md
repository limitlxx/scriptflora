### Day 1 — Problem  
**Title angle:** AI writing isn’t the bottleneck anymore

Most teams don’t struggle to get text out of AI.

They struggle with what happens next:

- The script is a wall of text  
- One change forces a full rewrite  
- Tone drifts across versions  
- Nobody owns continuity  

AI made drafting faster.  
It did not make production controlled.

The real gap is not generation.  
It’s direction.

---

### Day 2 — Method  
**Title angle:** Script-first beats prompt-first

If you jump straight from idea → video model, you inherit chaos.

A cleaner order:

1. Lock the brief  
2. Structure the script  
3. Freeze characters and style  
4. Break into shots  
5. Generate only what is approved  
6. Review in checkpoints  

This is the difference between “AI made a clip” and “AI worked inside a production system.”

Prompts matter.  
Process matters more.

---

### Day 3 — Problem (deeper)  
**Title angle:** Character drift is a systems failure

You can tell when an AI series is broken.

By clip 4, the lead looks slightly different.  
Wardrobe shifts.  
The face softens.  
Continuity becomes vibes.

That is not a model problem first.  
It is a reference and control problem.

If character identity is not locked before generation, every new shot is a reset.

No serious production runs that way.

---

### Day 4 — Method  
**Title angle:** Section-level control changes everything

The most useful AI feature in production is not “generate more.”

It is:

- Lock what works  
- Regenerate only what doesn’t  
- Keep key facts intact  
- Preserve upstream context  

Writers don’t need infinite drafts.  
They need surgical control.

When one scene changes, the whole script should not collapse.

---

### Day 5 — Proof / Build-in-public  
**Title angle:** What we’re learning building a Director system

While building ScriptFlora, one pattern keeps repeating:

Teams don’t ask for more AI.  
They ask for less chaos.

What testers value most so far:

- Structured briefs  
- Skill-based pipelines  
- Node-level regeneration  
- Human approval before things move downstream  

The product insight is simple:

Create with AI.  
Review with humans.  
Protect continuity in between.

---

### Day 6 — Category  
**Title angle:** The Director’s desk for AI film

Most tools are either:

- Writers that output text, or  
- Generators that output clips  

Few tools act like a director’s desk:

- Hold the brief  
- Enforce continuity  
- Break work into shots  
- Route generation intentionally  
- Require checkpoints before assembly  

That is the category that matters for ads, series, education, and long-form attempts.

Not one-click cinema.  
Directed production.

---

### Day 7 — Soft bridge  
**Title angle:** If this is your workflow, you’re not alone

If your current process looks like:

idea → long prompt → hope → rewrite → repeat

You already feel the limits.

A growing set of creators and teams are moving to:

brief → structured script → locked identity → shot plan → controlled generation → review

That shift is bigger than any single model release.

I’m building ScriptFlora around that system.

Create with AI. Review with humans.

## 4. Funding options (realistic order)

### 1) Revenue first (best leverage)
Even small MRR changes conversations.
- 30 users × $30 = $900/mo → real signal
- 5 studio pilots × $250 = $1,250/mo → stronger signal

Use income to cover:
- Model API costs
- Domain / basic tools
- One proof production budget

### 2) Grants (strong for this category)
Especially if you lean education + responsible AI creation:
- University innovation / entrepreneurship grants
- Creative industry / film board grants (country-dependent)
- AI-for-creators or digital arts funds
- Campus founder grants if you’re affiliated

Grants fit “teaching directed AI production” better than pure startup hype.

### 3) Donations / community support
Works if you have visible builder presence:
- GitHub Sponsors (if open parts exist)
- Buy Me a Coffee / Ko-fi for open process notes
- Community “support the Director desk” page
- Patron-style early supporter tier (access + credit)

This is bridge money, not a company strategy by itself.

### 4) Preseed angels
Only after you can show:
- Working product
- Active users/testers
- Proof short + process
- Clear next technical milestones (Character Bible, shot gen, etc.)
- Why now (AI video is chaotic; control layer is needed)

Raise for:
- API/compute budget
- 1 technical collaborator or contractor
- Proof-film production + festival run
- Basic infra beyond hobby Vercel limits

Target check size mindset: modest preseed, not fantasy seed.

### 5) Design partners (non-dilutive leverage)
Offer 2–3 film teams or a department:
- Free/cheap access
- Close feedback channel
- Case study rights
- Optional paid expansion later

Design partners create credibility capital.

## Unit-economics guardrails (do not skip)

Before locking numbers, measure 20 real test runs:

- Avg OpenAI cost per Brief + skill pipeline  
- Avg Runway cost per accepted 5s shot  
- Avg HyperFrames render cost  

Then set included credits so **median Creator user costs ≤ ~35–45% of subscription**.  
Heavy users buy packs or BYO keys.

If your measured costs are higher, raise price or lower included seconds immediately.
